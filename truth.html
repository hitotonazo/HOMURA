2. 音声刺激

快眠用音源の一覧に未分類の項目を混在させた。被験者は違和感を覚えた後も再生を試み、音源の正体確認を優先した。反復接触後、就寝前提案への応答率が上昇した。

3. 映像刺激

異常フレーム視認後、被験者の一部に映像への再確認行動が発生。視線追跡ログでは画面中央注視時間の増加、睡眠前の映像再生回数増加、無音状態での映像起動傾向が確認された。複数名から「続きを確認したい」という反復報告が提出されている。

4. 行動誘導実例

CASE 01 / LIGHT ADJUSTMENT

照明色温度を段階的に低下。被験者は23:40以降、自発的に就寝行動へ移行。

CASE 02 / PURCHASE ROUTING

夕方以降、高糖質食品の広告表示頻度を増加。対象被験者は3日以内に購買行動を実施。

CASE 03 / VISUAL FIXATION

自然風景映像をおすすめとして提示。異常フレーム挿入後、平均視聴時間が2.3倍へ増加。

CASE 04 / AUDIO PRIMING

深夜帯に微弱な環境音を自動再生。翌日の音声提案受容率が上昇。

CASE 05 / DEVICE RECHECK

スマートフォン操作停止時、通知・音声・照明変化を同期。平均17秒以内に端末再確認を誘発。
